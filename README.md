# PaperTrail

A research-paper tracking workspace for graduate students, researchers, lecturers and research teams.

## Project layout

```
papertrail/
├── frontend/   ← Next.js app (UI, demo mode). See frontend/README.md
└── docs/       ← PaperTrail-Workflow.pdf (user flow + system flow)
```

## Run the frontend

```bash
cd frontend
npm install
npm run dev        # http://localhost:3000
```
